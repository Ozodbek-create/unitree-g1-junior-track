# Unitree G1 Junior Track Submission

This repository contains my solutions for the Junior Track internship test.

## Part A — Human Motion to Robot

Generated a motion in UltimateBots Studio, exported it as LAFAN CSV, loaded the Unitree G1 29-DOF model in MuJoCo, and rendered the motion as an MP4.

Files are in `part_a/`.

## Part B — Walking Policy

Ran the pretrained G1 walking policy in MuJoCo and modified the velocity command so the robot walks in a circle.

Files are in `part_b/`.
